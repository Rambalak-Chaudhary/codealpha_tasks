<h1 align="center">🧮 Calculator Web App</h1>

<p align="center">
A simple and responsive calculator built using <b>HTML</b>, <b>CSS</b>, and <b>JavaScript</b>.
</p>

<hr>

<h2>📌 Project Overview</h2>
<p>
This project is a basic calculator that performs standard arithmetic operations such as addition, subtraction, multiplication, and division. It features a clean user interface with buttons and a display screen, along with real-time result updates.
</p>

<hr>

<h2>🚀 Features</h2>
<ul>
  <li>➕ Addition</li>
  <li>➖ Subtraction</li>
  <li>✖️ Multiplication</li>
  <li>➗ Division</li>
  <li>🧹 Clear screen functionality</li>
  <li>⚡ Real-time input and result display</li>
  <li>⌨️ Keyboard support (Bonus)</li>
  <li>🎨 Modern and responsive UI</li>
</ul>

<hr>

<h2>🛠️ Technologies Used</h2>
<ul>
  <li><b>HTML</b> – Structure of the calculator</li>
  <li><b>CSS</b> – Styling and layout design</li>
  <li><b>JavaScript</b> – Functionality and logic handling</li>
</ul>

<h2>🎯 How It Works</h2>
<ul>
  <li>User clicks buttons or types using keyboard</li>
  <li>Input is displayed on the screen</li>
  <li>JavaScript processes the input expression</li>
  <li>Result is calculated and shown instantly</li>
</ul>
