<h1 align="center">💼 Web Development Internship Projects</h1>

<p align="center">
A collection of beginner-friendly web projects built using <b>HTML</b>, <b>CSS</b>, and <b>JavaScript</b>.
</p>

<hr>

<h2>📌 Projects Included</h2>
<ul>
  <li>🧮 Calculator</li>
  <li>🖼️ Image Gallery</li>
  <li>🎵 Music Player</li>
</ul>

<hr>

<h2>🧮 1. Calculator Web App</h2>
<p>
A basic calculator that performs arithmetic operations with a clean UI and real-time result display.
</p>

<h3>🚀 Features</h3>
<ul>
  <li>Addition, Subtraction, Multiplication, Division</li>
  <li>Interactive buttons and display screen</li>
  <li>Clear screen functionality</li>
  <li>Keyboard support</li>
</ul>

<hr>

<h2>🖼️ 2. Image Gallery</h2>
<p>
A responsive image gallery with lightbox view, navigation controls, and smooth animations.
</p>

<h3>🚀 Features</h3>
<ul>
  <li>Grid layout for images</li>
  <li>Lightbox (popup) view</li>
  <li>Next/Previous navigation</li>
  <li>Hover effects and transitions</li>
  <li>Image filtering (categories)</li>
</ul>

<hr>

<h2>🎵 3. Music Player</h2>
<p>
A fully functional music player with audio controls, progress bar, and playlist support.
</p>

<h3>🚀 Features</h3>
<ul>
  <li>Play, Pause, Next, Previous controls</li>
  <li>Song title, artist, and duration display</li>
  <li>Progress bar with real-time updates</li>
  <li>Volume control</li>
  <li>Playlist and autoplay support</li>
</ul>

<hr>

<h2>🛠️ Technologies Used</h2>
<ul>
  <li><b>HTML</b> – Structure</li>
  <li><b>CSS</b> – Styling and layout</li>
  <li><b>JavaScript</b> – Functionality and interactivity</li>
</ul>
