<h1 align="center">🎵 Music Player Web App</h1>

<p align="center">
A stylish and interactive music player built using <b>HTML</b>, <b>CSS</b>, and <b>JavaScript</b>.
</p>

<hr>

<h2>📌 Project Overview</h2>
<p>
This project is a fully functional music player that allows users to play, pause, and navigate between songs. It displays song details like title, artist, and duration, along with a progress bar and volume control. The design is clean, responsive, and user-friendly.
</p>

<hr>

<h2>🚀 Features</h2>
<ul>
  <li>▶️ Play and pause music</li>
  <li>⏭️ Next and previous track navigation</li>
  <li>🎶 Display song title and artist</li>
  <li>⏱️ Show song duration and current time</li>
  <li>📊 Interactive progress bar</li>
  <li>🔊 Volume control</li>
  <li>📱 Responsive design</li>
  <li>🎼 Playlist support (Bonus)</li>
  <li>🔁 Autoplay next song (Bonus)</li>
</ul>

<hr>

<h2>🛠️ Technologies Used</h2>
<ul>
  <li><b>HTML</b> – Structure of the player</li>
  <li><b>CSS</b> – Styling and animations</li>
  <li><b>JavaScript</b> – Audio control and functionality</li>
</ul>

<hr>

<h2>🎯 How It Works</h2>
<ul>
  <li>User selects a song from the playlist</li>
  <li>Audio starts playing using JavaScript Audio API</li>
  <li>Controls allow play/pause, next, and previous</li>
  <li>Progress bar updates in real-time</li>
  <li>Volume can be adjusted dynamically</li>
</ul>
