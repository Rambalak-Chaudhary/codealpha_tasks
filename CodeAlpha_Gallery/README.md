<h1 align="center">🖼️ Image Gallery Web App</h1>

<p align="center">
A responsive and interactive image gallery built using <b>HTML</b>, <b>CSS</b>, and <b>JavaScript</b>.
</p>

<hr>

<h2>📌 Project Overview</h2>
<p>
This project is a modern image gallery that displays images in a clean grid layout. It includes interactive features like navigation buttons, a lightbox view, hover effects, and smooth transitions. The gallery is fully responsive and adapts to different screen sizes.
</p>

<hr>

<h2>🚀 Features</h2>
<ul>
  <li>🖼️ Grid-based image gallery layout</li>
  <li>🔍 Lightbox view for enlarged images</li>
  <li>⏮️ ⏭️ Next/Previous navigation buttons</li>
  <li>✨ Hover effects with smooth transitions</li>
  <li>📱 Fully responsive design</li>
  <li>🎛️ Image filters / categories (Bonus)</li>
</ul>

<hr>

<h2>🛠️ Technologies Used</h2>
<ul>
  <li><b>HTML</b> – Structure of the gallery</li>
  <li><b>CSS</b> – Styling, layout, and animations</li>
  <li><b>JavaScript</b> – Interactivity and navigation</li>
</ul>

<hr>

<h2>🎯 How It Works</h2>
<ul>
  <li>Images are displayed in a responsive grid layout</li>
  <li>Clicking an image opens it in a lightbox</li>
  <li>Users can navigate using next/previous buttons</li>
  <li>Hover effects enhance user interaction</li>
  <li>Optional filters allow sorting images by category</li>
</ul>
